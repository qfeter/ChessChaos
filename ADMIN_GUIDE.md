# Шахматы · Рулетка: шпаргалка администратора

## 1. Первый запуск (один раз)
1. Supabase → **SQL Editor → New query** → вставь весь `supabase.sql` → **Run**. Файл можно запускать повторно, ничего не сломается. Старые монеты и покупки сохраняются.
2. Supabase → **Authentication → Sign In / Providers → Email** → выключи **Confirm email**.
3. Залей содержимое папки `dist` (или zip) на хостинг (Netlify Drop, GitHub Pages и т.п.). QR-коды и ссылки вида `?join=КОД` работают только когда игра открыта по настоящему адресу `https://...`.
4. Ключи (`url` и `anon`) уже вписаны в `config.js`. Они публичные, это нормально. Секретный `service_role` нигде не нужен и не используется.

## 2. Новый скин фигур (без меня)
**Шаг 1. Картинки.** Supabase → **Storage → skins** (бакет уже создан скриптом, он публичный) → **New folder**, имя папки латиницей без пробелов, например `neon`. Внутрь загрузи файлы:

| Что | Имена файлов |
|---|---|
| Белые | `wk wq wr wb wn wp` |
| Чёрные | `bk bq br bb bn bp` |
| Особые (по желанию) | `wpg wvk wce wgn` и `bpg bvk bce bgn` (Пегас, Валькирия, Кентавр, Генерал) |

Расширение у всех одинаковое: `.png`, `.webp` или `.svg`. Лучше квадрат 256 или 512 px, прозрачный фон, до 100–200 КБ на файл. Если какого-то файла нет, вместо него рисуется стандартная фигура, ничего не ломается.

**Шаг 2. Товар.** SQL Editor:
```sql
insert into public.shop_items (id, kind, name, descr, price, meta)
values ('neon', 'skin', 'Неон', 'Светящиеся фигуры', 300, '{"ext":"png"}');
```
`id` = имя папки. `ext` = расширение файлов. Через минуту он появится в магазине во вкладке «Скины». Превью берётся из файла `wn` (белый конь).

## 3. Акции и временная продажа (считает сервер, подделать нельзя)
```sql
-- акция на 3 дня: вместо 200 будет 100 (товар виден во вкладке «Акции»)
update public.shop_items set sale_price = 100, sale_from = now(), sale_until = now() + interval '3 days' where id = 'pg';

-- временная продажа: товар исчезнет из магазина через 48 часов (купленное остаётся у игроков)
update public.shop_items set avail_until = now() + interval '48 hours' where id = 'neon';

-- начнётся завтра
update public.shop_items set avail_from = now() + interval '1 day' where id = 'neon';

-- убрать акцию / убрать товар из магазина
update public.shop_items set sale_price = null, sale_from = null, sale_until = null where id = 'pg';
update public.shop_items set active = false where id = 'neon';
```
Цену и срок проверяет база в момент покупки. Если игрок поменяет время на телефоне или подделает запрос, это ничего не даст.

## 4. Цены и описания
Цены стартовых способностей и особых фигур лежат в таблице `shop_items` (Table Editor). Меняй колонку `price`. Id: `call magic draft jackpot clown mirror pirate dynamite` (способности), `pg vk ce gn` (Пегас 200, Валькирия 2500, Кентавр 1000, Генерал 1250).

## 5. Админская способность Hollow Purple
Она не покупается и не выпадает. Выдаётся только строкой в `grants`:
```sql
insert into public.grants (nick, abilities) values ('mynick', '{purple}')
  on conflict (nick) do update set abilities = excluded.abilities;
```
Ник пиши **маленькими буквами**. Потом выйди и зайди в аккаунт, начни **новую** партию. Способность доступна после 5 своих ходов. Через `profiles.owned` выдать её нельзя, так задумано.

## 6. Что получает игрок
- Монеты и опыт: только за партии (победа 20 + бонусы за скорость и чистоту; против ботов умножается на 0,1 … 1,0 по уровню). Не чаще раза в 25 секунд и не больше 250 монет в сутки.
- Все покупки, награды, друзья и история идут через защищённые функции базы. Прямо подправить монеты из браузера нельзя.
- Игра без аккаунта работает, но монеты хранятся только на телефоне, а акции, скины, друзья и поиск соперников недоступны.

## 7. Если что-то не работает
- «Приложение не установлено» в APK: ставь подписанный `.apk`, не `.aab`; старую версию с другой подписью сначала удали.
- Не видно друзей / магазин пустой: проверь, что `supabase.sql` выполнился без ошибок (внизу должно быть `Success`).
- После обновления файлов игра может показывать старую версию: закрой её полностью и открой снова (сервис-воркер обновляется со второго запуска).
- Скин не показывается: открой в браузере адрес `https://<проект>.supabase.co/storage/v1/object/public/skins/neon/wn.png`. Если там не картинка, проверь имя папки и файла.
