Звук Hollow Purple
==================
Файл hollow_purple.mp3 (твоя запись, 51,85 с) уже лежит здесь и подключён: ничего делать не нужно.
Сцена идёт ровно по ней:
  0-25 с   жёлтый дым, пешка медленно взлетает и зависает в воздухе
  25 с     синий шар
  26 с     красный шар
  31 с     шары сближаются
  33 с     пешка приземляется
  34 с     «Hollow Purple» (надпись и голос из записи)
  37 с     выстрел фиолетового луча вперёд (шириной 3 клетки)
  37-51 с  дальше просто музыка, затем сцена заканчивается

Хочешь сдвинуть моменты? Создай рядом файл hollow_purple.json (секунды от начала записи), например:
  {"blue":25,"red":26,"merge":31,"land":33,"say":34,"beam":37}
Любой ключ можно не писать, тогда возьмётся значение по умолчанию.
Заменить саму музыку: положи другой mp3 с тем же именем hollow_purple.mp3.
Если длина записи будет другой, моменты пересчитаются пропорционально (или задай их в json).
